# MinifierLuaBot

A Discord bot with the following commands:

| Command | What it does |
|---|---|
| `.ping` | Check the bot's latency |
| `.get <url>` | Fetch the text content of a URL |
| `.checksyntax` (attach file / URL / text) | Check Lua/Luau syntax, returns Type/Why Error?/Line if there's an error |
| `.obf <level 1-4>` (attach file / URL / text) | Lightweight obfuscation: minify + randomize local variable names |

## What's NOT in this bot (on purpose)
A few commands from the original plan were left out because they fall
into categories that can be misused (bypassing other people's protections,
IP grabbing, junk-code techniques that resemble malware patterns):
`.l`, `.promdeobf`, `.luraph`, `.obfmax`, `.obfjunk`, `.ipaddres`.

## Deploying to Railway

This bot is a long-running process (not a web server), so on Railway it
runs as a **worker**, not a service with an exposed port.

1. **Push the project to GitHub** (create a new repo, push everything in
   this folder, including `Procfile` and `nixpacks.toml`, but **don't**
   push `.env` — it's already excluded via `.gitignore`).

2. Open [railway.app](https://railway.app) → **New Project** →
   **Deploy from GitHub repo** → pick your repo.

3. Railway automatically detects `Procfile` and `nixpacks.toml`:
   - `Procfile` tells Railway to run `python bot.py` as a worker
   - `nixpacks.toml` installs `lua5.1` in the container so `.checksyntax` works

4. In the **Variables** tab, add these environment variables:
   ```
   DISCORD_TOKEN = your_bot_token
   BOT_PREFIX = .
   ```
   (Don't use an `.env` file on Railway — secrets go through the Variables tab.)

5. Click **Deploy**. Check the **Deployments → Logs** tab, you should see:
   ```
   Logged in as YourBot#1234 (ID: ...)
   Prefix: .
   ```
   Once that shows up, the bot is online 24/7.

6. If Railway asks you to "expose a port" / requests an HTTP healthcheck —
   ignore or disable it, since a Discord bot doesn't need any open port at all.

### Running locally instead (without Railway)

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Copy `.env.example` to `.env`, fill in your Discord bot token:
   ```
   DISCORD_TOKEN=your_bot_token
   BOT_PREFIX=.
   ```

3. (Required for `.checksyntax`) Install one of these Lua/Luau checkers on
   the machine the bot runs on:
   - `luau-analyze` (from the [luau](https://github.com/luau-lang/luau) repo) — recommended, most accurate for Luau
   - or `luac`/`lua5.1` (plain Lua)

   If neither is installed, `.checksyntax` will return a warning instead
   of crashing.

4. Run the bot:
   ```bash
   python bot.py
   ```

## Project structure

```
bot.py                  - entry point, loads all cogs
cogs/general.py         - .ping, .get
cogs/syntax.py          - .checksyntax
cogs/obfuscate.py       - .obf
utils/minifier_lua.py   - minify + rename-variable engine
utils/input_source.py   - pulls code from attachment/URL/text
utils/lua_syntax.py     - wrapper around luau-analyze/luac
```

## `.obf` levels

| Level | Rename | Name length |
|---|---|---|
| 1 | no | - (minify only) |
| 2 | yes | 2-3 characters |
| 3 | yes | 4-6 characters |
| 4 | yes | 6-10 characters |

Every `.obf` result automatically gets this header:
```lua
-- [[ This file is generated by MinifierLuaBot ]]
```

## Adding your own commands

Create a new file in `cogs/`, e.g. `cogs/mycommand.py`:
```python
from discord.ext import commands

class MyCog(commands.Cog):
    def __init__(self, bot):
        self.bot = bot

    @commands.command(name="mycommand")
    async def mycommand(self, ctx):
        await ctx.send("Hello!")

async def setup(bot):
    await bot.add_cog(MyCog(bot))
```
Then register it in `bot.py` by adding `"cogs.mycommand"` to the `COGS` list.
